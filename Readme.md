# Express Voiture

application web pour la gestion du stock de la concession d'automobiles d'occasion 'Express Voiture'

## Stack

* projet ASP .NET Core MVC
* Framework ciblé : .NET 10
* Packages :
  * Microsoft ASP .NET Core Identity 10.0.12
  * Microsoft ASP .NET Core Entity Framework Core 10.0.12
* Moteur de base de données: MSSQL Server
